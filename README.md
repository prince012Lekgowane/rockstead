# Rockstead Projects Website

This repository contains the official website for Rockstead Projects, a Gauteng-based construction company specializing in residential renovations, high-quality finishes, and defect repair.

## About Rockstead Projects

Rockstead Projects is a premier construction company serving Pretoria, Johannesburg, and surrounding areas. We focus exclusively on home improvement, delivering exceptional results in:

- Residential renovations
- Bathroom and kitchen upgrades
- Ceiling, flooring, and painting services
- Defect repair and snag work

Our dedicated Snag Squad ensures every project is finished with precision and care, providing clean work, clear communication, and dependable service.
